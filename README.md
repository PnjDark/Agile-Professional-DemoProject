# To-Create

Lightweight project management web app for student teams.

## Project Structure

- `Design/` — UI prompts and design artifacts.
- `Planning/` — Project vision, backlog, and sprint planning.
- `src/` — Frontend source files.

## Quick Start

Open `src/index.html` in a browser to run the minimal prototype.

## Documents

- Project vision: `Planning/project_vision.md`
- Product backlog: `Planning/product_backlog.md`
- Sprint backlog: `Planning/sprint_backlog.md`
- UI prompts: `Design/ui_prompts.md`

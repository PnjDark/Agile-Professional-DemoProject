### Detailed User Story Descriptions

1. **Create Project**
   - As a Project Manager, I want to create a new project so that my student team can organize tasks in one place.

2. **User Management**
   - As an Administrator, I want to add and remove users so that only authorized team members can access the application.

3. **Role Assignment**
   - As a Project Manager, I want to assign roles to team members so that each person has the correct permissions.

4. **Role-based Task View**
   - As a Team Member, I want to view tasks assigned to my role so that I can focus on my own responsibilities.

5. **Create Task**
   - As a Team Member, I want to create a new task so that I can capture work items that need to be completed.

6. **Edit Task**
   - As a Team Member, I want to edit task details so that I can update progress, priority, or due dates.

7. **Delete Task**
   - As a Team Member, I want to delete tasks that are no longer needed so that the project board stays relevant.

8. **Task Generation from Objectives**
   - As a Project Manager, I want the system to generate tasks based on project objectives so that task creation is faster and more aligned.

9. **Task Filtering**
   - As a Team Member, I want to filter tasks by status, priority, or project so that I can focus on what matters most.

10. **Project Dashboard**
    - As a Project Manager, I want to view all projects in one dashboard so that I can oversee the entire workload.

11. **Role-Based Access Control**
    - As an Administrator, I want to manage user roles and permissions so that I can enforce role-based access control.

12. **Task Completion**
    - As a Team Member, I want to mark tasks as complete so that my progress is visible to the rest of the team.

13. **Search**
    - As a Project Manager, I want to search for projects or tasks quickly so that I can find items without wasting time.

14. **Responsive Interface**
    - As a Team Member, I want a responsive interface so that I can manage tasks from both desktop and mobile devices.

15. **Intuitive Layout**
    - As an Administrator, I want the application to provide a simple, intuitive layout so that new users can learn it quickly.

16. **Project Objectives Setup**
    - As a Project Manager, I want to set project objectives so that generated tasks reflect the goals of the team.

17. **Clear Task Details**
    - As a Team Member, I want to receive clear task details so that I understand what needs to be done.
